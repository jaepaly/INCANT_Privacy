# INCANT 상용 서비스 모델 (To-Be)

> **To-Be 문서**입니다. 가정에 기반하며, 가정의 근거는
> [01_policy_benchmark.md](01_policy_benchmark.md)의 실제 업계 관찰입니다.
> 실제 배포된 데모의 사실 기록은 [As-Is 흐름표](../as-is/01_data_flow_asis.md)에 있습니다.

## 이 문서의 위치

개인정보 인벤토리를 만들려면 먼저 **어떤 서비스인지**가 정의되어야 합니다.
이 문서가 그 정의이며, [03_data_inventory.md](03_data_inventory.md)가 여기서 도출됩니다.

**가정의 규율**

- 기능·시스템 구성은 국내 게임사 6곳의 실제 처리방침에서 관찰된 구조를 따릅니다
- 수탁 유형과 사업자는 벤치마크에서 실제로 확인된 것을 씁니다 (지어내지 않습니다)
- 보유기간은 법정 보존기간(원문 확인 완료)과 관찰된 정책 기간을 근거로 합니다
- **INCANT 고유의 부분** — 자유 텍스트를 외부 생성형 AI로 처리하는 구조 — 은 벤치마크 대상이 없어 직접 설계합니다. 그 사실을 §5에 명시합니다

## 1. 서비스 개요

| 항목 | 내용 |
|---|---|
| 서비스명 | INCANT |
| 형태 | 웹·모바일 로그라이크 게임 |
| 핵심 기능 | 이용자가 **자유 문장으로 입력한 주문**을 LLM이 판정해 게임 효과로 변환 |
| 수익모델 | 인앱 결제 (게임 재화·시즌패스) |
| 서비스 지역 | 국내 + 글로벌 (EU 포함) |
| 적용 관할 | 대한민국 개인정보 보호법 + GDPR |

**As-Is 데모와의 차이 — 개인정보 관점에서 결정적인 것들**

| | As-Is (데모) | To-Be (상용) |
|---|---|---|
| 계정 | 없음 | **있음** — 입력 내용이 식별된 개인에 결합 |
| 결제 | 없음 | 있음 — 법정 보존 의무 발생 |
| 고객센터 | 없음 | 있음 — 자유 텍스트·첨부파일 채널 추가 |
| 이용자 제재 | 없음 | 있음 — 제재 이력 보유기간 문제 |
| 연령 | 확인 불가 | 확인 절차 필요 (관할별 기준 상이) |
| EU 이용자 | 대상 아님 | **대상** — GDPR 무조건 적용 |

> **계정의 도입이 가장 큰 변화입니다.** As-Is에서 `F-005`(자유 텍스트 유입)를 LOW로
> 판정한 근거가 "결합할 정보가 없다"였는데, 계정이 생기면 그 근거가 사라집니다.

## 2. 서비스 기능

```text
회원가입 ─ 본인확인 ─ 로그인
    │
    ├── 게임 플레이 ── 자유 텍스트 주문 입력 ── LLM 판정
    │                        └── 주문서(그리모어) 저장
    ├── 랭킹·기록
    ├── 결제
    ├── 고객센터 문의
    ├── 이벤트 참가
    ├── 마케팅 수신
    ├── 이용자 제재 (부적절 입력 차단)
    └── 회원 탈퇴
```

| V-02 | **Google (Gemini API)** | **§5.1 참조** | 주문 텍스트 의미 판정 | 미국 | **해당** |
| V-03 | 코리아크레딧뷰로 | 위탁 | 본인확인·연령확인 | 대한민국 | 미해당 |

> 공개합니다(제26조 제6항 기반으로 보임 — U-11 미확인). To-Be도 이 수준을 따릅니다.

### 5.1 미해결 설계 쟁점 — LLM 판정은 위탁인가 제3자 제공인가

**이 프로젝트에서 가장 중요한 미해결 문제이며, 벤치마크에 선례가 없습니다.**

| 구분 | 논거 | 귀결 |
|---|---|---|
| **위탁**(제26조) | 서비스 제공에 필요한 처리를 대행시키는 것이며, 이용 목적이 위탁자의 목적에 종속됨 | 별도 동의 불요. 수탁자 공개 + 계약 필요 |
| **제3자 제공**(제17조) | 수신자가 자기 목적(모델 품질 개선·학습)으로 쓸 여지가 있으면 제공에 가깝다 | **별도 동의 필요**. 서비스 진입 장벽이 커짐 |

판단은 **Google이 입력 데이터를 자기 목적으로 이용하는지**에 달려 있고,
그것은 API 약관과 데이터 처리 조건이 결정합니다.

→ **선행 확인 필요 (U-01)**: Gemini API의 입력 보관·학습 이용 정책.
확인 전까지 이 문서는 어느 쪽도 확정하지 않습니다.

> 이것이 As-Is `F-002`에서 이어지는 질문입니다. 그때는 "이전 근거가 없다"였는데,
> To-Be에서는 "**어떤 근거를 선택할 것인가**"로 바뀝니다.

### 5.2 이전 거부 시의 대체 경로

제28조의8 제2항 제5호는 **이전 거부 방법·절차·효과**를 알리도록 요구합니다.
그런데 이 서비스에서 이전 거부는 곧 **판정 기능 미제공**입니다.

벤치마크에서 확인된 실무 답안:

> **크래프톤** — 전용 창구(`privacy@krafton.com`)로 거부 가능. 거부 시 이전 대상에서
> 제외하되 **해당 서비스 이용이 제한될 수 있음**을 함께 고지.

INCANT에 적용하면 세 가지 선택지가 있습니다.

| 안 | 내용 | 평가 |
|---|---|---|
| A | 거부 시 게임 이용 불가 | 단순하나 사실상 거부권 형해화 |
| B | 거부 시 **로컬 판정(규칙 기반) 폴백** | 기능 저하는 있으나 이용 가능. 개인정보 보호 친화적 |
| **C** | 기본을 로컬 판정으로 두고 LLM 판정은 **옵트인** | 가장 보호적. 다만 핵심 재미가 옵트인 뒤에 있음 |

→ To-Be는 **B안**을 채택합니다. 거부권이 실질을 갖되 서비스가 성립하며,
As-Is 코드에 이미 `MockJudge` 폴백 경로가 존재해 구현 가능성이 확인됩니다.

### 5.3 연령 게이트 — 관할 분기

벤치마크에서 6개사가 서로 다른 해법을 쓰는 것이 확인되었고,
**GDPR Art.8의 회원국별 하향 재량(13~16세)을 반영한 곳은 펄어비스 한 곳뿐**입니다.

| 관할 | 기준 |
|---|---|
| 대한민국 | 만 14세 미만 → 법정대리인 동의 및 동의 여부 확인 (제22조의2 제1항) |
| EU | 16세 미만 → 친권자 동의. **회원국이 법으로 13세까지 하향 가능** (Art.8(1)) |

→ To-Be는 **관할 판별 후 기준 분기** 구조를 채택합니다. 단일 게이트로는 두 관할을
동시에 만족시킬 수 없다는 것이 As-Is `F-006`에서 도출된 결론이며, 업계 관찰이 이를
뒷받침합니다.

### 5.4 자유 텍스트 원문 보관 여부

As-Is에서 `rawText`가 무기한 저장되는 것이 `F-003`으로 잡혔습니다.
To-Be에서는 **보관 자체를 할 것인가**가 먼저 결정되어야 합니다.

| 안 | 내용 |
|---|---|
| 보관 | 주문서(그리모어) 재사용 기능이 성립. 개인정보 노출면 유지 |
| **미보관** | 판정 결과(구조화된 SpellSpec)만 저장하고 원문 폐기. 최소수집 원칙에 부합 |

→ To-Be는 **원문 미보관**을 기본으로 하고, 주문서 기능은 판정 결과와 이용자가 명시적으로
저장을 선택한 항목으로 구성합니다. GDPR Art.5(1)(c) 최소수집 관점에서 가장 강한 통제이며,
저장 측 위험(`F-003`·`F-005`)을 구조적으로 제거합니다.

## 6. 보유기간 정책의 근거

### 6.1 법정 보존기간 — 원문 확인 완료 (U-10 해소)

| 대상 | 기간 | 근거 | 확인 |
|---|---|---|---|
| 표시·광고에 관한 기록 | 6개월 | 전자상거래법 제6조 제1항, 시행령 제6조 제1항 | 법제처 |
| 계약 또는 청약철회 등에 관한 기록 | **5년** | 〃 | 법제처 |
| 대금결제 및 재화등의 공급에 관한 기록 | **5년** | 〃 | 법제처 |
| 소비자의 불만 또는 분쟁처리에 관한 기록 | **3년** | 〃 | 법제처 |
| 장부 및 증거서류 | **5년** (역외거래 7년) | 국세기본법 제85조의3 | CaseNote |

### 6.2 통신비밀보호법 3개월 — **적용 여부에 유보를 답니다**

벤치마크에서 6개사 중 다수가 접속기록 보존 근거로 통신비밀보호법을 인용합니다.
원문을 확인한 결과 주의가 필요합니다.

- **제15조의2의 조 제목은 "전기통신사업자의 협조의무"** 이며, 의무 주체가 **전기통신사업자**입니다
- 보관기간은 조문에 없고 **시행령에 위임**되어 있습니다 (시행령 제41조, 최소 3개월)
- 즉 이는 **모든 서비스 사업자에게 일반적으로 적용되는 개인정보 보존 의무가 아닙니다**

→ 게임 사업자가 전기통신사업법상 부가통신사업자로서 여기에 포섭되는지, 게임 접속로그가
"통신사실확인자료"에 해당하는지는 별도 판단이 필요합니다.

→ **U-12로 남기고, 인벤토리에는 이 근거를 확정 기재하지 않습니다.**
관행적으로 인용된다는 사실만 기록합니다.

> 이 유보가 이 문서에서 벤치마크를 그대로 베끼지 않은 유일한 지점입니다.
> 업계가 인용한다고 해서 우리 인벤토리의 근거가 되지는 않습니다.
