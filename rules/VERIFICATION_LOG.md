# 근거 조문 검증 기록 — 2026-08-10

룰 카탈로그 v0.1의 근거 조문 26건에 대한 검증 기록입니다.

## 방법

**1차 근거는 원문입니다.** 모델의 답변은 원문을 대체하지 않습니다.
교차검증은 원문을 잘못 읽거나 빠뜨린 것을 찾기 위한 보조 수단으로만 씁니다.

| 단계 | 수행 | 역할 |
|---|---|---|
| 1차 | 원문 대조 (CaseNote·법제처 easylaw·EUR-Lex·gdpr-info) | **판정 근거** |
| 2차 | Codex CLI 독립 검증 | 후보 오류 제기 |
| 2차 | Gemini CLI 독립 검증 | 후보 오류 제기 |
| 3차 | 불일치 항목을 원문으로 재확인 | 최종 판정 |

원문 접근에 막힌 경로도 기록해 둡니다:

- **국가법령정보센터(law.go.kr)** — JS 렌더링이라 본문 추출 불가. 조문 페이지·조문 링크 페이지 모두 메타정보만 반환.
- **EUR-Lex 전문(CELEX:32016R0679)** — 본문 추출이 recital 구간에서 잘려 조항 본문에 도달하지 못함.
- **LBOX** — 403. **한국법제연구원 elaw** — JS 렌더링.

따라서 국내법은 CaseNote 조문 페이지와 법제처 '찾기쉬운 생활법령정보'로,
GDPR은 gdpr-info.eu 조항별 페이지로 대조했습니다. 각 `legal_basis`의 `source`가
실제로 읽은 URL입니다. 공식 문서에 인용할 때는 EUR-Lex·국가법령정보센터 본문으로
다시 대조해야 합니다.

| | 내용 |
|---|---|

| 제기 | Codex (`FIX`) |

| 확인 | 법제처 [찾기쉬운 생활법령정보](https://www.easylaw.go.kr/CSP/CnpClsMain.laf?csmSeq=1257&ccfNo=2&cciNo=2&cnpClsNo=3) — "제16조에는 기한 규정이 없으며 '지체 없이' 기준은 모법 제21조에서 온다"고 명시 |

이 건이 이번 검증에서 가장 중요한 결과입니다. 한 모델이 **확신도 "높음"으로 구체적인
수치("5일 이내")까지 붙여 틀린 답**을 냈고, 다른 모델이 잡아냈으며, 최종 판정은 원문이
했습니다. 모델 합의를 근거로 삼았다면 오류가 그대로 남았을 것입니다.

## 정밀화 1건

### 제28조의8 — 항 단위로 분리

원문 확인 결과 구조가 드러나 인용을 나눴습니다.

- **제1항** — 국외 이전을 원칙적으로 금지하고, 각 호에 예외(별도 동의, 법률·조약, 계약 이행에 필요한 처리위탁·보관, 인증, 보호수준 인정)를 둔다
- **제2항** — 제1항 제1호 동의를 받을 때 미리 알려야 할 5개 사항: ① 이전되는 개인정보 항목 ② 이전되는 국가·시기·방법 ③ 이전받는 자의 성명(법인은 명칭·연락처) ④ 이전받는 자의 이용목적 및 보유·이용 기간 ⑤ 이전 거부 방법·절차 및 거부의 효과

`KR-TRF-001`의 개선 조치와 요구 증적을 제2항 각 호에 맞춰 구체화했습니다.
부수적으로 **제2항 제5호(이전 거부 방법·절차)가 To-Be 설계 쟁점을 만듭니다** —
판정을 외부 LLM에 맡기는 구조에서 '이전 거부'는 곧 기능 미제공을 뜻하므로,
거부 시 대체 경로를 어떻게 둘지 결정해야 합니다.

## 판단 보류 2건

### U-05 · EDPB Guidelines 3/2018 (Art.3(2) 역외 적용)

`eu.yaml`의 `applicability`가 근거로 삼는 해석입니다.

- Codex `OK` — EDPB 공식 문서 URL 제시
- Gemini `OK` — 확신도 높음
- **원문 미확인** — 가이드라인 본문을 직접 읽지 않았습니다

두 모델이 일치하고 문서 번호도 실재하지만, 원문을 읽지 않았으므로 확정하지 않습니다.
현재 `applicability` 서술은 이 해석에 의존하고 있으니 후속 확인이 필요합니다.

### U-06 · 한국 적정성 결정의 재이전 커버 범위

**확인된 사실** (EUR-Lex 원문):
Commission Implementing Decision (EU) 2022/254, **2021-12-17 채택**, 대한민국 대상,
GDPR Art.45(3) 근거. → [CELEX:32022D0254](https://eur-lex.europa.eu/legal-content/EN/TXT/?uri=CELEX%3A32022D0254)

**엇갈린 부분** — 이 결정이 한국에서 미국 등 제3국으로의 **재이전(onward transfer)** 을
어느 범위까지 커버하는가:

| | 판단 |
|---|---|
| Codex | 재이전을 자동 허용하지 않으며 blanket 근거로 쓸 수 없다 |
| Gemini | Supplemental Rules를 통해 보호 수준 유지가 보장되어 실질적으로 커버한다 |

**어느 쪽도 채택하지 않았습니다.** 결정문 본문과 Supplemental Rules를 직접 읽어야
판단할 수 있습니다.

다만 이와 별개로, **Art.44 원문에 Chapter V의 조건이 재이전에도 적용된다고 명시**되어
있음은 확인했습니다. 따라서 두 번째 구간(KR→US)을 검토 대상에서 제외할 수는 없다는
점까지는 확정입니다. `EU-TRF-001`은 이 확정된 범위까지만 서술합니다.

## 이번 검증에서 확인한 것

1. **모델 합의는 검증이 아닙니다.** Gemini는 26/26을 "확신도 높음"으로 통과시켰고 그중 하나는 틀렸습니다. 두 모델이 일치했다면 오류가 남았을 것입니다.
2. **틀린 답은 모르는 답처럼 보이지 않습니다.** "5일 이내"처럼 구체적인 수치가 붙어 있으면 오히려 더 신뢰하게 됩니다.
3. **교차검증의 실제 쓸모는 판정이 아니라 후보 제기입니다.** Codex가 제기한 2건을 원문으로 확인하는 것이 이번 검증의 실질이었습니다.
4. **접근 실패도 기록해야 합니다.** law.go.kr에서 본문을 못 읽었다는 사실은 검증 강도의 한계이며, 나중에 다시 확인할 지점입니다.
